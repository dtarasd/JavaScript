# Data Transformation Library

Бібліотека функцій вищого порядку для трансформації даних у функціональному стилі.

## Опис реалізованих функцій
- myMap, myFilter, myReduce: власні чисті реалізації стандартних методів масивів без мутацій.
- Chain API: клас-обгортка `_()`, що дозволяє викликати функції трансформації ланцюжком (chainable API).
- compose: функція, що поєднує декілька функцій та виконує їх справа наліво.
- pipe: функція, що поєднує декілька функцій та виконує їх зліва направо.
- curry: функція каррінгу, яка трансформує функцію від багатьох аргументів у ланцюжок функцій, кожна з яких приймає один аргумент.
- partial: функція часткового застосування, що фіксує частину аргументів заздалегідь.
- memoize: декоратор для кешування результатів роботи чистих функцій задля оптимізації.

## Інструкція
- Відкрити файл index.html у браузері.
- Використовувати кнопки на екрані для запуску демонстраційних тестів кожної функції.
- Результат виконання з поясненнями миттєво виводиться у блок під кнопками.
