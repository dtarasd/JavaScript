# Аналіз алгоритмів сортування

У цьому проєкті реалізовано п'ять класичних алгоритмів сортування масивів.

## Опис алгоритмів та їхня складність
- Bubble Sort (Сортування бульбашкою): найпростіший метод, що порівнює сусідні елементи. Складність $O(n^2)$.
- Selection Sort (Сортування вибором): шукає мінімальний елемент та ставить його на початок. Складність $O(n^2)$.
- Insertion Sort (Сортування вставками): будує відсортований масив по одному елементу. Складність $O(n^2)$.
- Merge Sort (Сортування злиттям): рекурсивно ділить масив навпіл і зливає відсортовані частини. Складність $O(n \log n)$.
- Quick Sort (Швидке сортування): використовує опорний елемент для поділу масиву. Середня складність $O(n \log n)$.
