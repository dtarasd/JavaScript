# Система управління студентами

Проста система для зберігання та обробки даних про студентів.

## Опис функціоналу
- реалізовано додавання нових студентів до масиву
- додано сортування студентів за балом через метод sort
- створено пошук за ім'ям за допомогою методу find
- виводиться статистика, така як середній бал та найкращий студент, через метод reduce

## Інструкція
- відкрити файл index.html у браузері
- для додавання студента заповнити всі поля та натиснути Додати
- для сортування натиснути відповідну кнопку
- для отримання статистики натиснути Показати статистику
- для пошуку ввести ім'я та натиснути Знайти
