# Task Tracker та трансформації масивів

Інтерактивний додаток для трекінгу завдань та демонстрації роботи алгоритмів трансформації масивів.

## Опис функціоналу
- створено систему управління задачами з можливістю додавання, видалення та зміни статусу
- реалізовано збір базової статистики по статусах задач (виконано, у процесі, очікує)
- написано функцію flatten для рекурсивного розгортання вкладених масивів
- написано функцію groupBy для групування масиву об'єктів за вказаним ключем
- написано функцію unique для відфільтровування дублікатів з масиву
- написано функцію chunk для розбиття масиву на підмасиви заданої довжини

## Інструкція
- відкрити файл index.html у браузері
- скористатися формою для додавання нових задач
- кнопки біля кожної задачі дозволяють змінити її статус або видалити запис
- натиснути кнопку "Тест трансформацій" та відкрити консоль браузера (F12), щоб перевірити роботу алгоритмів обробки масивів
