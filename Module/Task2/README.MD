# Обробка товарів

Функція `processProducts(products)` обробляє масив товарів для формування звіту.

## Реалізовані методи
- `filter`: Для вибірки товарів, що є в наявності.
- `map`: Для створення списку назв та переліку цін.
- `reduce`: Для обчислення загальної суми товарів у наявності.

## Вихідні дані
- `available`: Масив назв доступних товарів.
- `totalPrice`: Сума цін доступних товарів.
- `cheapest`: Назва найдешевшого доступного товару.
- `priceList`: Список цін у форматі "Назва — Ціна грн".
