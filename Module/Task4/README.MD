# TodoList Application

Веб-додаток для керування списком завдань.

## Структура
- `Task`: Клас завдання (id, text, done).
- `TodoList`: Клас для керування колекцією завдань (add, remove, getActive).

## Як запустити
1. Відкрийте файл `index.html` у браузері.
2. Використовуйте поле вводу та кнопку "Додати" для створення завдань.
3. Клік по завданню перемикає його статус (закреслення).
4. Кнопка "Видалити" прибирає завдання зі списку.
