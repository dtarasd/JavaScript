# GitHub User Explorer

Це моя практична робота, в якій я розробив додаток для перегляду профілів користувачів GitHub та їхніх репозиторіїв.

## Що я реалізував у цьому завданні
- використав async/await для асинхронних запитів через Fetch API
- зробив паралельне завантаження профілю та списку репозиторіїв через Promise.all
- додав паралельні запити для отримання списку мов, тексту README та контриб'юторів для кожного репозиторію
- зробив кешування результатів через об'єкт Map, щоб не робити зайві запити до сервера
- додав локальне сортування репозиторіїв за зірками, форками та датою оновлення
- реалізував обробку помилок через try/catch, включаючи перехоплення ліміту запитів від GitHub

## Як запустити та перевірити
- відкрити файл index.html у браузері
- ввести існуючий нікнейм користувача GitHub у поле пошуку
- вибрати потрібне сортування з випадаючого списку
- натиснути кнопку Знайти або клавішу Enter на клавіатурі
- для перевірки кешування можна здійснити пошук того ж самого користувача ще раз
- для перевірки обробки помилок можна ввести неіснуючий нікнейм
