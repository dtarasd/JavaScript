# Modal System

Це інтерактивна система модальних вікон, реалізована за допомогою JavaScript, HTML та CSS.

## Опис функціоналу
- створено два різних типи модальних вікон: інформаційне (alert) та вікно підтвердження (confirm)
- реалізовано закриття вікна по кліку на темний фон поза ним (overlay click)
- додано можливість закриття активного вікна за допомогою клавіші ESC
- налаштовано плавні CSS-анімації для появи та зникнення модалок

## Інструкція
- відкрити файл index.html у браузері
- натискати на верхні кнопки для відкриття відповідних вікон
- протестувати різні способи закриття: клік по кнопках всередині вікна, натискання клавіші ESC на клавіатурі або клік мишею по темному фону навколо вікна
