# Kanban Board

Це інтерактивна канбан-дошка, створена за допомогою JavaScript, HTML та CSS.

## Опис функціоналу
- реалізовано три колонки: To Do, In Progress, Done
- додавання нових задач через кнопку
- можливість перетягувати картки між колонками за допомогою Drag API

## Інструкція
- відкрити файл index.html у браузері
- натиснути кнопку додавання задачі та ввести текст
- затиснути створену картку лівою кнопкою миші та перетягнути в потрібну колонку
