# Форма та пошук

Інтерактивна сторінка з валідацією форми та системою пошуку.

## Опис функціоналу
- реалізовано контактну форму з live-валідацією полів
- додано прогрес-бар заповнення
- створено компонент пошуку по списку з 30+ елементів
- додано підсвічування знайденого тексту та затримку debounce

## Інструкція
- відкрити файл index.html у браузері
- почати вводити дані у форму для перевірки валідації та роботи прогрес-бару
- внизу сторінки ввести назву фрукта у поле пошуку для фільтрації списку
