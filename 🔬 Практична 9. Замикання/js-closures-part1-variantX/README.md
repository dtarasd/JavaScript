# Паттерни замикань: Counter Factory

Проєкт демонструє використання замикань (closures) у JavaScript для створення ізольованих об'єктів з приватним станом (інкапсуляція).

## Опис реалізованих функцій
- createCounter: фабрика для створення простого лічильника зі стандартним кроком в одиницю. Стан (змінна count) надійно схований всередині замикання.
- createLimitedCounter: лічильник, який приймає мінімальне та максимальне значення. Містить вбудовану валідацію, що не дозволяє вийти за вказані межі.
- createStepCounter: лічильник, який збільшує або зменшує своє значення на заданий при ініціалізації крок.
- createNamedCounter: просунутий лічильник, що містить ім'я та записує кожну дію (increment/decrement) у приватний масив history. Метод getHistory повертає лише копію масиву для захисту даних від мутацій.

## Інструкція
- Відкрити файл index.html у браузері.
- Використовувати кнопки плюс та мінус біля кожного лічильника для перевірки їхньої логіки (наприклад, спробувати вийти за ліміт 5 у другому лічильнику).
- Для іменного лічильника зробити кілька кліків, після чого натиснути кнопку виводу історії та відкрити консоль розробника (F12), щоб побачити детальний лог транзакцій.
