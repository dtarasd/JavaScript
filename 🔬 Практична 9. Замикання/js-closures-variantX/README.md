# Memoization Library

Бібліотека для просунутої мемоізації функцій у JavaScript за допомогою замикань.

## Реалізовані функції
- `memoize(fn, limit)`: базова мемоізація з підтримкою обмеження розміру кешу за алгоритмом LRU. Зберігає статистику (hits, misses).
- `memoizeWith(keyFn, fn)`: дозволяє передати кастомну функцію для генерації ключа кешування.
- `memoizeAsync(fn)`: адаптована версія для роботи з Promise та асинхронними функціями, що запобігає дублюванню паралельних запитів.
- `memoizeExpiring(fn, ttlMs)`: кеш з автоматичним скиданням значення після закінчення заданого часу життя (TTL).

## Бенчмарки та тестування
- У проєкті реалізовано порівняння швидкості виконання рекурсивної функції обчислення чисел Фібоначчі з мемоізацією та без неї.
- Візуалізовано логіку роботи LRU кешу через виведення статистики влучень та промахів.
- Проведено тестування асинхронних викликів на базі імітації API-запитів.

- Використовувати кнопки інтерфейсу для запуску бенчмарків і тестів кожної стратегії кешування.
