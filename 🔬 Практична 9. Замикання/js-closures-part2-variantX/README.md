# Cache Manager та Lazy Evaluation

У цьому проєкті реалізовано просунуті техніки роботи з функціями та замиканнями: систему кешування та систему відкладених (ледачих) обчислень.

## Опис функціоналу
- createCache: створює замикання для управління кешем. Підтримує алгоритм витіснення LRU (Least Recently Used) при перевищенні ліміту. Кожен запис має свій час життя (TTL), після якого вважається недійсним. Додано метод збору статистики (кількість влучень та промахів).
- lazy: функція для відкладеного виконання переданого колбеку. Результат обчислюється лише при першому виклику, а далі повертається з кешу замикання.
- lazyList: функція для роботи з безкінечними генераторами. Дозволяє брати потрібну кількість елементів через метод take або створювати новий ледачий генератор через метод map. Для прикладу реалізовано генератор простих чисел.

## Інструкція
- відкрити файл index.html у браузері
- у першій секції натиснути кнопку додавання в кеш, а потім спробувати отримати дані (через 2 секунди дані автоматично зникнуть через TTL)
- у другій секції скористатися кнопками для генерації ледачої послідовності простих чисел та їх трансформації на льоту
