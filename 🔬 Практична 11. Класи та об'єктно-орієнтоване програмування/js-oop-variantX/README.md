# Система управління транспортом (ООП)

Проєкт демонструє практичне застосування об'єктно-орієнтованого програмування (ООП) у JavaScript з використанням ES6 класів.

## Опис реалізованих функцій та принципів ООП
- **Класи та наслідування:** Створено базовий клас `Vehicle`, від якого через ключове слово `extends` успадковуються класи `Car`, `Truck` та `Motorcycle`. Використовується виклик `super()` для ініціалізації властивостей батьківського класу.
- **Інкапсуляція:** У базовому класі поля `#mileage` (пробіг) та `#fuelLevel` (паливо) зроблені приватними. Доступ до них ззовні здійснюється виключно через гетери або методи управління (`drive` та `refuel`).
- **Поліморфізм:** Метод `getMaintenance()` розраховує вартість обслуговування по-різному для базового транспорту, легковика та вантажівки (перевизначення методів у дочірніх класах).
- **Статичні методи:** У класі `Vehicle` реалізовано статичний метод `filterByType`, який працює без створення екземпляра класу.
- **Клас Fleet:** Відокремлений клас для зберігання масиву транспортних засобів та агрегації статистики.

## Інструкція
- Відкрити файл `index.html` у браузері.
- Використовувати форму зверху для додавання нового транспортного засобу потрібного типу.
- На картках авто натискати кнопки "Їхати" та "Заправити", щоб змінювати стан об'єктів. Зверніть увагу, що при вичерпанні палива автомобіль не зможе їхати.
- Використовувати кнопки фільтрації та статистики для аналізу поточного автопарку.
