Shopping Cart System

Опис структур даних:

Product: звичайний об'єкт, який описує товар. Містить поля id, name та price.

CartItem: клас, що зберігає посилання на товар, фіксує його кількість та ціну на момент додавання. Має метод для розрахунку проміжної вартості конкретної позиції.

ShoppingCart: головний клас, що керує масивом об'єктів CartItem. Стан кошика, наприклад масив товарів та інформація про знижки, надійно схований у приватних полях класу для безпеки.
